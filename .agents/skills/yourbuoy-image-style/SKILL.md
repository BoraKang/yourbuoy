# yourBuoy Image Style

yourBuoy 썸네일은 글을 자세히 재현하는 삽화가 아니라, 글의 중심 생각을
상징 하나로 줄인 넓은 가로형 그래픽이다. 새 이미지를 만들기 전에 아래

## 시각 문법

- 가로 약 1.9:1. 썸네일에서 즉시 읽히는 큰 형태를 쓴다.
- 배경은 단색 또는 아주 약한 명도 변화만 둔다.
- 가로 전체가 썸네일로 보였을 때 비어 보이지 않도록 중심 상징과 보조
  요소를 화면 전반에 균형 있게 배치한다. 한쪽을 카피 영역처럼 의도적으로
  비워두지 않는다.
- 상징의 수는 적게 유지하되 크기·간격·반복·방향성을 이용해 프레임 전체를
  사용한다. 단순함은 빈 화면이 아니라 명확한 화면을 뜻한다.
- 평면 벡터 그래픽, 단순한 기하 형태, 선명한 실루엣을 기본으로 한다.
- 팔레트는 배경을 포함해 3~5색으로 제한한다. 청록·파랑·보라·코럴 계열처럼
  기존 이미지와 어울리는 색을 고른다.
- 그림자는 쓰더라도 단순한 긴 그림자나 한 덩어리로 처리한다.
- 사람은 필요할 때만 넣고, 얼굴 표정이나 인물 묘사는 최소화한다.
- 글자, 제목, 로고, 워터마크는 넣지 않는다.

## 피해야 할 것

- 여러 장면을 액자·패널·콜라주로 나열하기
- 영화 같은 조명, 사실적인 공간, 종이 질감, 회화적 붓터치
- 감정을 자세한 표정과 상황극으로 설명하기
- 작은 소품이 많은 사무실 풍경
- 일반적인 기업용 스톡 이미지, 과도한 3D 렌더링
- 본문 내용을 모두 설명하려는 복잡한 은유

## 작업법

1. 글의 핵심을 명사형 상징 한두 개로 줄인다.
2. 기존 이미지 중 가장 가까운 2~3개를 시각 기준으로 고른다.
3. 이미지 생성 도구에 `minimal flat vector`, `solid-color background`,
   `balanced full-width composition`, `no dead empty zones`,
   `3–5 color palette`, `no text`를 명시한다.
4. 결과에서 디테일이 많거나 장면이 둘 이상 보이면 단순화해 다시 만든다.
5. 프로젝트의 front matter 경로와 같은 파일명으로 저장한다. 기존 파일을
   대체할 때는 사용자의 수정 요청이 있는지 확인한다.

성공 기준은 예쁜 이미지가 아니라, 기존 썸네일 목록 사이에 놓았을 때 같은
블로그에서 나온 이미지처럼 보이는가이다.
