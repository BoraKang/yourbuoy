## 스펙과 구조

구글 워크스페이스 애드온이다. 크롬 익스텐션이 아니라 애드온인 이유는 하나다. 익스텐션은 화면에 보이는 것만 바꿀 수 있고 문서 자체를 수정하지 못한다. 애드온은 구글 API를 거쳐 문서를 직접 고치므로 변경이 파일에 저장되고, PDF로 내려받아도 유지된다.

배포는 조직 내부용이다. 마켓플레이스 유료 배포는 요건을 확인하고 접었다.

## 어떻게 동작하나

사이드바에서 아이콘을 눌러 연다. 폰트명을 넣고 적용을 누르면 문서 안의 텍스트 상자와 표가 한꺼번에 바뀐다. 개체를 따로 고를 필요가 없다.

인수 기준으로 정해 둔 조건은 다섯 개였다.

* 슬라이드, 독스, 스프레드시트 중 최소 1종에서 동작하는 폰트 일괄 변경 기능
* 문서 전체 또는 선택 범위 기준으로 변경 가능할 것
* 지정한 폰트로 본문, 제목, 표, 기본 스타일이 일관되게 바뀔 것
* 스크립트 실행이나 간단한 메뉴 형태로 비개발자가 재사용할 수 있을 것
* 테스트 문서 1종 이상에서 변경 전후 비교가 가능할 것

## 한계

이미지 안에 그려진 글자는 바꾸지 못한다. 편집이 제한된 레이어도 접근하지 못한다.

스타일만 건드리고 내용은 지우지 않으므로 사고가 날 여지는 적은 편이다. 다만 되돌리기는 문서의 버전 기록에 의존한다.
