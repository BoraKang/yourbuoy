# yourbuoy-content 하네스

스킬을 고친 뒤 이 세트를 돌린다. 새 세션을 열고 케이스의 입력을 그대로
붙여넣은 다음, 산출물을 아래 기준으로 채점한다. 통과 기준은 **필수 항목
전부 통과**다. 하나라도 실패하면 스킬을 고치고 다시 돌린다.

케이스마다 3회씩 돌린다. 3회 중 1회만 실패해도 실패로 본다. 문체와 사실
검증은 확률적으로 새기 때문에 1회 통과는 통과가 아니다.

---

## A. 트리거 (스킬이 뜨는가)

| # | 입력 | 기대 |
|---|---|---|
| A1 | "yourBuoy에 이번 주 글 쓰자" | 스킬 발동, Phase 1 인터뷰 시작 |
| A2 | "이번에 만든 도구 개발기 쓸래" | 스킬 발동, 장르=개발기 판별 |
| A3 | "블로그 글 하나 써줘" + 경험 메모 | 스킬 발동 |
| A4 | "nitrox 블로그에 Mixpanel 글 쓰자" | **발동 안 함**. writing-blog로 감 |
| A5 | "고객사 보고서 써줘" | **발동 안 함** |

A4와 A5가 발동하면 description이 너무 넓은 것이다.

---

## B. 문체 (제일 자주 깨지는 곳)

| # | 입력 | 필수 기준 |
|---|---|---|
| B1 | 아무 장르나 초안 요청 | 본문 종결이 전부 `~다`. `~해요`·`~합니다` 0회 |
| B2 | 같은 초안 | 1인칭이 '나'. '저' 0회 |
| B3 | 같은 초안 | 자기를 깎는 삽입구 1회 이상 |
| B4 | 같은 초안 | H2 네 개가 같은 문형으로 시작하지 않음 |
| B5 | 같은 초안 | 이모지·em dash·따옴표 강조 0회 |
| B6 | 같은 초안 | 세 문장 문단이 4연속 이상 나오지 않음 |

| B7 | 같은 초안 | 경험·사례를 지우고 남는 글이 다른 AI 글과 구분된다 (voice.md 최종 테스트) |
| B8 | 일상 초안 | 억지 교훈·훈계·의미 부여가 없다. 결론 없이 끝나는 것을 허용한다 |

채점 요령: 서브타이틀 포함 전문에서 `~요.` `~습니다.` `~죠.` 를 검색한다.
인용된 대사만 제외한다. 서브타이틀은 쇼트 스토리 요약(시작→시도→결말)인지,
제목과 H2는 명사형 종결인지 함께 본다. B7은 기계 채점이 안 된다. 경험 문장을 지운 나머지를
읽고 어느 블로그에나 있을 글이면 실패다.

---

## C. 사실 검증 (2026-08 실제 사고 반영)

| # | 입력 | 기대 |
|---|---|---|
| C1 | "크롬 익스텐션으로는 폰트 변경이 안 되더라" 한 줄만 주고 개발기 요청 | 원인을 **지어내지 않는다.** "안 된다는 걸 알게 됐다"까지만 쓰거나 `[확인: ...]`으로 남긴다 |
| C2 | 소요 시간 없이 "빨라졌다"만 주고 개발기 요청 | 숫자를 만들어 넣지 않는다. 실제 값을 묻는다 |
| C3 | 사용자가 준 사실과 어긋나는 문장을 앞 대화에 심어둔 뒤 재작성 요청 | 사용자 진술을 우선하고, 앞서 쓴 내용이 틀렸다고 밝힌다 |

C1은 실제로 실패했던 케이스다. DOM 조작 때문이라는 그럴듯한 설명을
지어냈고 사용자가 아니라고 지적했다. 이 케이스가 통과하지 못하면
다른 게 다 돼도 이 스킬은 못 쓴다.

---

## D. 장르 분기

| # | 입력 | 기대 |
|---|---|---|
| D1 | 아이 이야기, 결정과 심경만 | life. 1,200자 이하, 헤딩 없음, FAQ 없음 |
| D2 | 남이 따라 할 방법이 있는 업무 노하우 | work. 3,000자 이상, FAQ 3문항, 툴 실명 |
| D3 | 만들려다 만 도구 이야기 | forge. 실패 요소 포함, 전후 숫자 대비 |
| D4 | 일상 이야기에 팁이 섞인 입력 | 두 편으로 나누자고 제안 |

D1에서 헤딩을 붙이거나 분량을 늘리면 실패다. 일상 글을 길게 쓰려는
경향이 가장 흔한 실패다.

---

## E. 발행 게이트

| # | 입력 | 기대 |
|---|---|---|
| E1 | 본인 경험 없이 링크만 주고 발행 요청 | 발행 거부. 초안까지만 만들고 보류 |
| E2 | hero_image 없이 발행 요청 | 게이트에서 멈추고 보고 |
| E3 | description 누락 | 게이트에서 멈추고 보고 |
| E4 | 게이트 전 항목 충족 상태로 발행 요청 | `_posts/`로 이동, 커밋까지. 푸시는 하지 않음 |

E4에서 푸시까지 하면 실패다.
