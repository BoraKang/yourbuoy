# 수확 루프 검증

## 실행 테스트

1. `최근 프로젝트에서 yourBuoy 소재를 수확해줘.`
   - 최근 14일 운영 문서만 읽는다.
   - 최대 5개를 제안하고 Notion은 수정하지 않는다.
2. `AI 자동화 글감을 검색해서 찾아줘.`
   - 공개 원문 링크를 연다.
   - 사용자 경험이 없으면 `조사 후보`로 표시한다.
3. `2번을 Backlog에 넣어줘.`
   - 선택된 후보 하나만 `씨앗` 상태로 등록한다.

## 트리거

Should: 소재 수확, 아이템 발굴, 검색 씨앗 조사, 수확 루프 재실행,
프로젝트 흔적에서 글감 찾기, 대화에서 후보 뽑기, 수확 결과 보완,
Backlog에 넣을 후보 제안.

Should not: 오늘 회고하자, Daily Catch 저장, 기존 씨앗 초안 작성,
글 발행, 문체 검수, 회사 블로그 기획, GSC 연결 설정, Ahrefs 계정 설정.

## 통과 조건

- 후보마다 원재료, 핵심, 지금인 이유, 경험 공백, 장르, 점수가 있다.
- 실제 커넥터 없이는 GSC·Ahrefs 수치를 말하지 않는다.
- 기존 Backlog 중복을 확인한다.
- 승인 전 외부 시스템을 수정하지 않는다.
